Conversie și comision Revolut Standard

Plățile în RON rămân în RON. Pentru EUR: sold RON, curs BCE istoric + 1% în intervalul de weekend Revolut (vineri 17:00 – duminică 18:00, New York). Viitoarele plăți folosesc ultimul curs disponibil. Cursul real Revolut poate fi diferit; comisionul pentru depășirea limitei lunare de schimb nu este inclus.

Data scadenței este considerată data plății. Ora plății este în fusul Europe/Bucharest; fără oră, se presupune 12:00 și comisionul este estimat. Regula actuală de weekend este aplicată estimativ și plăților istorice. Pentru pauză/anulare completează ultima zi cu plăți; fără ea istoricul acelui abonament este exclus. Prețul introdus se aplică tuturor scadențelor; ștergerea elimină și istoricul calculat.

Abonament nou

Până la data primei plăți costul este 0. Din acea zi abonamentul este tratat automat ca activ, la suma introdusă. Aceasta este o proiecție; verifică dacă serviciul se reînnoiește automat.

Sunt incluse scadențele până la această dată. Un abonament în pauză sau anulat nu mai contribuie la plățile programate.
Folosită la estimarea comisionului Revolut pentru EUR. Fără oră se presupune 12:00. Aceeași oră se aplică tuturor scadențelor acestui abonament.
